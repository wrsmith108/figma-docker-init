# Development Documentation Archive

This directory contains internal development documentation, reports, and artifacts that are not intended for end users.

## Contents

- **qa/** - QA reports, test validation, and quality assurance documentation
- **retrospectives/** - Sprint retrospectives and learnings
- **planning/** - Project planning, roadmaps, and phase checklists
- **reports/** - Performance reports, refactoring summaries, test summaries
- **specifications/** - Technical specifications for features
- **implementations/** - Implementation-specific documentation
- **development/** - Active development tracking and capabilities
- **releases/** - Internal release notes and deployment documentation
- **research/** - Research documents and investigations
- **skills/** - Claude Code skill documentation
- **fixes/** - Fix documentation and analysis
- **templates/** - Document templates (retrospectives, token estimation)
- **security/** - Security audit reports and analysis

These documents are version controlled but hidden from the public repository structure.
They provide historical context and development insights for maintainers.
