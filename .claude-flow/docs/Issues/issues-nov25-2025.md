# Docker Build Issues - November 25, 2025

## Original Issue

Docker container was failing to build with COPY errors:

| Property  | Value                                    |
| --------- | ---------------------------------------- |
| Container | task-management-app-prototype-figma-make |
| Image     | vibe-docker-figma-make-app               |
| Status    | Running (health check starting)          |
| Port      | 3000 → 3000                              |

The app should be accessible at http://localhost:3000

### Manual Fixes Applied (User Workaround)

1. Added COPY package\*.json ./ to the builder stage (needed for npm run build)
2. Added COPY serve.json ./ to the builder stage (needed for the production stage)

---

## Root Cause Analysis

The Dockerfile templates had missing COPY statements that caused build failures:

1. **`COPY index.html ./`** - Failed if project doesn't have index.html at root (e.g., Next.js projects)
2. **`COPY --from=builder /app/serve.json ./`** - Failed because serve.json was never copied TO the builder stage
3. **serve.json** is generated by vibe-to-docker but wasn't being included in Docker build context

---

## Fix Applied to NPM Package (v5.2.1+)

### Files Modified

1. **`src/templates/base/Dockerfile.base`**
   - Added `RUN touch index.html serve.json` to create placeholders
   - Changed `COPY index.html ./` to `COPY index.htm[l] ./` (bracket notation for optional files)
   - Added `COPY serve.jso[n] ./` to copy serve.json to builder stage
   - Added fallback: creates default serve.json if missing

2. **`src/templates/tools/figma-make/Dockerfile`**
   - Added serve.json creation in builder stage if missing
   - Added `COPY --from=builder /app/serve.json ./serve.json` in production stage
   - Updated CMD to use `-c serve.json` flag for proper SPA routing

3. **`src/templates/tools/lovable/Dockerfile`**
   - Same fixes as figma-make (both use `serve` for static file hosting)

### Default serve.json Content

When serve.json is missing, the templates now create a default SPA configuration:

```json
{
  "rewrites": [{"source": "**", "destination": "/index.html"}],
  "cleanUrls": true
}
```
