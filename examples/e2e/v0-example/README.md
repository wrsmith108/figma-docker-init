# V0 Example - Landing Page

This is a complete end-to-end example demonstrating how to use **vibe-to-docker** with a [V0 by Vercel](https://v0.dev) generated project.

## Project Overview

This is a modern landing page built with:
- **Next.js 14** - React framework with App Router
- **React 18** - UI framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Utility-first styling
- **Lucide React** - Beautiful icons

This represents a typical project structure generated by V0, which uses Next.js App Router with modern best practices.

## Project Structure

```
v0-example/
├── app/

│   ├── page.tsx            # Landing page
│   └── globals.css         # Global styles
```

## Running Without Docker

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Build for production:

```bash
npm run build
npm start
```

## Dockerizing with vibe-to-docker

### Step 1: Install vibe-to-docker

```bash
npm install -g vibe-to-docker
```

### Step 2: Initialize Docker Configuration

From the project root, run:

```bash
vibe-to-docker basic
```

Or for optimized setup:

```bash
vibe-to-docker ui-heavy
```

This will:
1. Detect your project type (Next.js + TypeScript)
2. Auto-detect build output directory (`.next` or `out`)
3. Generate Docker configuration in `.vibe-docker/`
4. Assign available ports for services
5. Create `.env` from `.env.example`

### Step 3: Review Generated Configuration

Check the `.vibe-docker/` directory:

```
.vibe-docker/
├── Dockerfile            # Multi-stage Docker build
├── docker-compose.yml    # Service orchestration
├── .env                  # Environment variables
├── .env.example          # Environment template
├── nginx.conf            # Nginx configuration
└── DOCKER.md             # Docker documentation
```

### Step 4: Build and Run

Navigate to `.vibe-docker/` and start the containers:

```bash
cd .vibe-docker
docker-compose up -d --build
```

### Step 5: Access Your Application

The application will be available at:
- **Development**: http://localhost:3000 (hot reload enabled)
- **Production**: http://localhost:8080 (Next.js server)
- **Nginx Proxy**: http://localhost:8888 (production with caching)

### Step 6: View Logs

```bash
cd .vibe-docker
docker-compose logs -f
```

## Next.js-Specific Considerations

### Build Modes

V0 projects can use different Next.js build modes:

#### 1. Standalone Output (Recommended for Docker)

In `next.config.js`:
```javascript
const nextConfig = {
  output: 'standalone',
}
```

This creates a self-contained Node.js server in `.next/standalone/`.

#### 2. Static Export

For fully static sites:
```javascript
const nextConfig = {
  output: 'export',
}
```

This generates static HTML in the `out/` directory.

### Environment Variables

Next.js supports multiple environment variable types. Add to `.vibe-docker/.env`:

```env
# Public variables (exposed to browser)
NEXT_PUBLIC_API_URL=https://api.example.com

# Server-only variables
DATABASE_URL=postgresql://...
API_SECRET=your-secret-key
```

### Image Optimization

Next.js Image Optimization requires a Node.js server. In Docker:

- **Standalone mode**: Image optimization works
- **Static export**: Use `unoptimized: true` in next.config.js

## Advanced Configuration

### Adding Database (PostgreSQL)

Edit `.vibe-docker/docker-compose.yml`:

```yaml
services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: myapp
      POSTGRES_USER: user
      POSTGRES_PASSWORD: password
    volumes:
      - postgres-data:/var/lib/postgresql/data
    ports:
      - "5432:5432"

volumes:
  postgres-data:
```

Update `.vibe-docker/.env`:
```env
DATABASE_URL=postgresql://user:password@postgres:5432/myapp
```

### Adding Redis for Caching

```yaml
services:
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
```

### Custom Nginx Configuration

Edit `.vibe-docker/nginx.conf` to add custom headers, caching rules, etc.

## Troubleshooting

### Build Errors

Ensure TypeScript types are valid:

```bash
npm run lint
npm run build
```

### Port Conflicts

Check `.vibe-docker/.env` for assigned ports. Modify if needed:

```env
DEV_PORT=3000
PROD_PORT=8080
NGINX_PORT=8888
```

### Image Optimization Issues

If using static export, disable image optimization in `next.config.js`:

```javascript
const nextConfig = {
  output: 'export',
  images: {
    unoptimized: true,
  },
}
```

### Server-Side Rendering Issues

Check logs for SSR errors:

```bash
cd .vibe-docker
docker-compose logs app
```
